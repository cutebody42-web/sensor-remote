# SENSOR branding

`sensor-logo.jpeg` is the unmodified logo supplied by the product owner on
2026-09-06, originally named `WhatsApp Image 2026-09-03 at 9.56.43 PM.jpeg`.
The Windows application embeds this exact file. The build performs only an
aspect-preserving size/ICO conversion for the executable icon; it does not
redraw or crop the artwork. No generated replacement branding is used.
