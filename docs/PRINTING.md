# Remote Printing

Remote printing is not implemented yet.

The planned Windows component is an explicitly installed `SENSOR Remote
Printer` virtual printer. It will capture a print job, transport it through
the authorized encrypted session, show the controller a local-printer choice,
and expose queue status, cancellation, retry, paper settings, duplex, and
color mode. Administrative rights and user-visible installation are required.

Downloading a PDF is not considered remote printing.
